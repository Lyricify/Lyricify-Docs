Lyricify Fusion 自 **1.3.0** 起提供曲目与歌词管理功能，支持保存在线歌词、选择歌词版本、导入本地歌词及调整歌词偏移。如果自动获取的歌词不正确，或需要使用其他版本的歌词，则可以通过该功能进行修改。

## 打开曲目与歌词管理

右击系统通知栏（托盘）中的 Lyricify Fusion 图标，展开 `曲目与歌词管理`，选择对应入口：

| 入口 | 说明 |
| --- | --- |
| `当前播放` | 查看和管理当前播放曲目的歌词。切换曲目后，窗口会自动更新。 |
| `全部曲目` | 查看和管理已保存的曲目与歌词，无需先播放对应曲目。 |

你也可以在 `设置 → 歌词 → 曲目与歌词管理 → 管理已保存的歌词` 中点击 `打开`，进入全部曲目。

:::tip[先播放一首歌]
使用“当前播放”时，需要播放器提供播放信息。如果窗口中没有可用会话或播放曲目，请先在[支持的播放器](../supported-apps/)中播放歌曲。仍然无法识别时，请参考[无法检测到播放器](../faq/cannot-detect-player/)。

如果需要管理已保存的曲目，也可以直接打开 `曲目与歌词管理 → 全部曲目`，无需先播放歌曲。
:::

## 搜索与更换歌词

如果自动获取的歌词不正确，或需要更换歌词版本，则可以通过以下步骤实现：

1. 打开 `当前播放`，确认窗口顶部显示的曲目信息。也可以在 `全部曲目` 中选择需要管理的曲目。
2. 在 `歌词源` 列表中选择一个在线来源，右侧会显示对应的曲目信息和歌词预览。
3. 点击 `更换版本 → 搜索并选择版本`。如果该来源尚未保存歌词，按钮会显示为 `获取歌词`。
4. 在搜索结果中选择对应曲目，核对歌名、艺人、专辑、时长及歌词预览，注意区分录音室版、现场版、翻唱版等不同版本。
5. 点击 `获取并保存此版本`，返回管理窗口。
6. 选中已保存的版本，点击 `固定使用`。如果主按钮显示为 `确认版本`，则可以点击旁边的下拉箭头，选择 `固定使用`。
7. 播放曲目，在灵动词岛、桌面歌词或其他歌词视图中检查歌词内容和时间轴是否正确。

**注意：** 点击歌词源仅显示预览，`获取并保存此版本` 仅将歌词保存至本机。如果需要指定该曲目使用此版本，还需要点击 `固定使用`。如需保留自动选择，则可以使用 `确认版本`，具体区别见下方[歌词版本与使用方式](#selection)。

| 区域 | 说明 |
| --- | --- |
| 曲目 | 搜索、筛选和选择已保存的曲目，查看曲目信息。仅在“全部曲目”中显示。 |
| 歌词源 | 查看在线词源、本地歌词及其状态，选择歌词版本，通过 `添加歌词` 添加其他版本。 |

“曲目”指需要管理的歌曲，“词源”指提供歌词的来源，“版本”指该曲目保存的一份歌词。同一曲目可以保存不同词源的歌词及多份本地歌词。

“逐行”“逐字”“逐音节”“翻译”等标签表示该版本包含的歌词信息。逐字高亮需要歌词本身包含逐字或逐音节时间轴；仅有逐行时间轴的歌词无法提供对应的逐字效果。

## 歌词版本与使用方式

曲目与歌词管理提供以下使用方式：

| 使用方式 | 说明 | 适用情况 |
| --- | --- | --- |
| `固定使用` | 指定该曲目使用某个版本，直至取消固定或更改选择。 | 已确定需要使用某个歌词版本。 |
| `确认版本` | 将在线版本标记为已确认，自动选择时优先按当前词源顺序使用已确认版本。 | 歌词已确认正确，但仍需按词源顺序自动选择。 |
| 普通缓存 | 保留已获取的在线歌词，作为对应词源的已有结果参与自动选择。 | 保留歌词，暂不确认或固定。 |

固定版本优先于自动选择。未固定版本时，程序先考虑已确认版本，再根据词源顺序和匹配规则选择歌词。实际用于播放的版本会显示“正在使用”标签。

点击 `歌词源` 标题旁的信息按钮，可以查看当前选择规则。“全部曲目”中的会话选项可以用于查看不同播放器对应的规则。

### 取消固定或确认

- **在线版本：** 点击 `取消固定` 后，该版本仍为已确认状态，重新参与自动选择。如果需要将其恢复为普通缓存，可以继续点击 `取消确认`。
- **本地歌词：** 点击 `使用版本`（使用此版本）后，该版本会固定用于当前管理的曲目。点击 `恢复自动选择` 可取消固定，已保存的本地歌词仍会保留。

上述按钮会根据所选版本的状态变化，部分操作位于主按钮旁的下拉菜单中。

**注意：** 确认和固定仅修改本机的使用偏好，不会将歌词上传至 Lyricify 4 的公共词库。固定版本仍受[自动更新已保存的在线歌词](#storage)设置影响。

## 在线歌词导入

### 通过 ID 或链接指定版本

如果自动搜索无法找到正确版本，则可以在对应音乐平台查找曲目，并通过歌曲 ID 或链接导入：

1. 选择对应的在线歌词源，点击 `获取歌词` 或 `更换版本`。
2. 选择 `通过 ID 或链接指定版本`，输入该词源的歌曲 ID 或链接。
3. 点击 `解析`，确认曲目信息正确后，点击 `获取并保存此版本`。
4. 返回管理窗口，选择 `固定使用` 或 `确认版本`。

QQ 音乐词源支持歌曲 ID、MID 或 `y.qq.com` 链接；网易云音乐词源支持歌曲 ID 或 `music.163.com` 链接。其他词源支持的输入形式，以导入窗口中的提示为准。

**注意：** 输入的 ID 或链接必须属于所选词源，且对应具体歌曲。

### 补全在线词源

点击 `添加歌词 → 补全在线词源`，程序会尝试获取当前已启用、但尚未保存歌词的在线词源。完成后，可以选择各版本查看歌词及翻译，并设置使用方式。

该操作不会替换已有版本。如需重新搜索已有词源，请使用 `更换版本`。

## 本地歌词导入与编辑

### 导入歌词文件

1. 在 `当前播放` 中确认曲目，或在 `全部曲目` 中选择需要管理的曲目。
2. 点击 `添加歌词 → 导入本地歌词文件`，选择歌词文件。
3. 在编辑窗口中检查歌词内容和 `歌词格式`，点击 `保存`。
4. 返回管理窗口，选中新增的本地歌词，点击 `使用版本`，将其固定用于该曲目。
5. 播放曲目，检查歌词内容和时间轴是否正确。

支持的格式包括 LRC、QRC、KRC、YRC、TTML、Lyricify Lines 和 Lyricify Syllable。文件选择器也支持 `.xml` 扩展名的 TTML 文件。歌词内容需要符合对应格式，并包含有效的时间轴。

### 从文本添加歌词

点击 `添加歌词 → 从文本添加歌词`，选择歌词格式，粘贴含时间轴的歌词内容，再点击 `保存`。保存后，同样需要选择该版本并点击 `使用版本`。

例如，LRC 格式如下：

```text
[00:05.00]第一句歌词
[00:10.00]第二句歌词
```

`[00:05.00]` 表示该句歌词从第 5 秒开始。只有正文、没有时间轴的文本无法用于同步歌词；`.txt` 文件不支持直接导入，仅修改扩展名也无法将普通文本转换为歌词。歌词制作方法可参考[歌词指南及标准](/lyrics/guide/)。

如果需要添加翻译，可以在编辑窗口中切换至 `中文翻译（可选）`，填写与主歌词对应的带时间轴翻译，再点击 `保存`。

### 编辑与重命名

选中本地歌词，点击 `更多（···）→ 编辑本地歌词`，即可修改已保存的内容。同一菜单中的 `重命名` 可以修改版本名称。

在线歌词不支持直接编辑。如需修改在线歌词内容，可以将歌词文本添加为本地版本后编辑。

## 歌词偏移

如果歌词内容正确，但时间轴整体提前或滞后，可以为对应版本设置歌词偏移：

1. 选择需要调整的版本，点击 `更多（···）→ 调整歌词偏移`。
2. 在效果预览窗口中启用 `跟随播放`，播放对应曲目，修改 `歌词偏移`。
3. 确认时间轴正确后，点击 `保存偏移`。

偏移单位为毫秒，`1000 ms = 1 秒`。正值使歌词延后，负值使歌词提前。例如，当前偏移为 0 时：

| 时间轴偏差 | 调整方法 |
| --- | --- |
| 歌词提前 500 毫秒 | 将偏移设置为 `500` ms。 |
| 歌词滞后 500 毫秒 | 将偏移设置为 `-500` ms。 |

**注意：**

1. 在预览窗口中修改数值后，需要点击 `保存偏移` 才会保存。点击 `重置` 可将数值恢复为 0，之后也需要保存。
2. 没有活动播放会话时，效果预览使用模拟播放。检查实际同步效果时，需要播放对应曲目并启用 `跟随播放`。
3. 如果歌词各部分的时间轴偏差不同，则无法通过整体偏移修正，建议更换时间轴正确的版本。
4. 如果所有曲目均存在相似的时间轴偏差，可以检查设备与应用延迟设置。

## 曲目与版本管理

### 搜索、筛选与排序

“全部曲目”支持按歌名、艺人或专辑搜索，使用 `Ctrl + F` 可以定位至搜索框。也可以按使用方式、是否包含本地歌词、已存词源等条件筛选，并按最近管理、最近播放或标题排序。

如果列表未显示新保存的曲目，可以点击右上角的 `刷新曲目库`，并检查筛选条件。该按钮仅重新载入曲目和歌词版本列表，不会重新搜索或下载歌词。

### 更新与删除

| 操作 | 说明 |
| --- | --- |
| `更多 → 重新获取此版本的歌词` | 使用已保存的 ID 或链接重新下载同一版本的歌词。 |
| `更换版本 → 自动搜索并替换` | 重新搜索该词源并替换已存版本，保留固定、确认或缓存状态。 |
| `更多 → 删除此版本` | 删除选中的歌词版本，其他版本仍会保留。 |
| 右击曲目 → `从曲库删除曲目` | 删除该曲目及其全部已存歌词版本，需要在提示框中确认。 |

从曲库删除曲目不会删除播放器中的歌曲或本地音频文件。再次播放时，符合自动保存条件的歌词仍可能被重新保存。

### 复制与查看原始歌词

通过歌词预览区的复制菜单，可以复制歌词正文、正文与翻译或带时间轴的文本。点击 `更多 → 查看原始歌词`，可以查看该版本保存的原始歌词数据。

## 保存设置

在 `设置 → 歌词 → 曲目与歌词管理` 中，可以修改以下选项：

| 设置 | 说明 |
| --- | --- |
| 自动保存在线歌词 | 将选中的可用歌词保存至本地，是否自动保存取决于 `自动保存最低匹配`。 |
| 自动更新已保存的在线歌词 | 使用已保存的在线歌词时，在后台检查并保存更新。 |
| 曲目与歌词管理开关 | 默认开启。关闭后不再读取或自动保存歌词，已有数据仍会保留。 |

单个播放器也有对应的曲目与歌词管理开关，关闭后该应用仅在线搜索歌词。

## 常见问题

### 保存后未使用所选版本

确认管理的曲目与正在播放的曲目一致，并检查是否已固定其他版本。仅保存或预览歌词不会固定使用；在线版本需要选择 `固定使用`，本地版本需要选择 `使用版本`。

如果选择了 `确认版本`，则程序仍按已确认版本的词源顺序自动选择。还需要确保全局及对应播放器的曲目与歌词管理开关已开启。

### 搜索或链接导入失败

检查词源是否启用、网络连接是否正常，并按窗口提示完成所需的授权。没有搜索结果时，可以修改关键词，或在对应音乐平台查找正确曲目，再通过 ID 或链接导入。

搜索到曲目不代表该曲目有可用歌词。没有时间轴或纯音乐结果可能无法作为同步歌词保存。

### 歌词没有逐字时间轴或翻译

检查所选版本是否包含对应标签。翻译还需要在 `设置 → 歌词` 中启用 `中文翻译`。更换歌词源不会为原歌词添加缺失的逐字时间轴或翻译。

### 全部曲目中没有显示已播放的歌曲

自动保存受 `自动保存在线歌词` 和 `自动保存最低匹配` 设置影响，播放过的曲目不一定会被保存。可以手动获取或导入歌词，再点击 `刷新曲目库` 查看，并检查是否启用了筛选。

### 迁移曲目与歌词数据

曲目与歌词数据保存在本机，不会自动同步至其他设备。如需迁移，请参考[配置文件迁移](../faq/config-migration/)，退出两台设备上的 Lyricify Fusion 后，复制配置目录中的 `LyricsCatalog.db`。仅复制 `Settings.json` 不会迁移曲目与歌词库。
