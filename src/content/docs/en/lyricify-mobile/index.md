title: Lyricify Mobile User Guide
---

Lyricify Mobile runs on Android, iPhone, iPad, and Mac. Windows support ended in v1.6.0; Windows users can use [Lyricify 4](../lyricify-4/) or [Lyricify Fusion](../lyricify-fusion/).

## Playback source support

Lyricify Mobile supports the following playback sources:

| Platform | Supported playback sources |
| --- | --- |
| Android | Spotify, players with Media Session support |
| iOS and iPadOS | Spotify, Apple Music |
| macOS | Spotify, players with Media Session support |
